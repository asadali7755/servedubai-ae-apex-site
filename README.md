# servedubai.ae (temporary GitHub Pages copy)

Static export of the live site, served on the bare domain `servedubai.ae` from
GitHub Pages. The main deployment is on Cloudflare Pages; the domain's
registrar account is not available right now, so its nameservers cannot be
moved to Cloudflare, and Cloudflare Pages only serves a bare domain whose zone
is on Cloudflare.

This copy has no redirects, 410 rules or contact-form backend. Once the
nameservers move to Cloudflare, attach servedubai.ae to the Cloudflare Pages project
and delete this repository.
